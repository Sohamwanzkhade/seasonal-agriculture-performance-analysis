# 🌾 Seasonal Agriculture Performance Analysis

A Python-based data visualization and analytics project studying agricultural performance across seasons, environmental conditions, resource usage, regions, and economic outcomes.

## Dataset
- 4,000 records
- 28 variables

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Jupyter Notebook

## Analysis
- Data exploration and cleaning
- Seasonal yield and profit comparison
- Environmental conditions vs yield
- Irrigation and water efficiency
- Fertilizer vs yield
- Correlation analysis
- Regional profitability
- ANOVA seasonal comparison
- Exceptional-yield/outlier investigation
- Yield vs profit analysis
- Crop × season heatmap
- Evidence-based insights and recommendations


Open `Seasonal_Agriculture_Performance_Analysis_FINAL.ipynb` and run the cells from top to bottom.

## Note
The analysis distinguishes association from causation. Recommendations are based on patterns observed in the supplied dataset.
